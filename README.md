# Gym Tracker

Full-featured offline-first Progressive Web App for tracking gym workouts.

## Features
- Log workouts (sets, reps, weight, notes)
- Routines / templates
- Workout history
- Personal Records (auto-detected)
- Progress charts
- Body weight tracking
- Rest timer
- Fully offline (IndexedDB)
- Export to CSV
- Installable on mobile
- Dark mode

## Tech Stack
React + TypeScript + Vite + Tailwind + Dexie + Recharts + PWA

## Getting Started
```bash
npm install
npm run dev
```
